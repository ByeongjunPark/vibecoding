# 🚀 구글 도구와 함께하는 바이브코딩으로 교수학습 콘텐츠 만들기

왕초보 교사를 위한 8차시 실습형 바이브코딩 과정 교보재입니다.

## 📚 과정 구성

| 차시 | 주제 | 도구 |
|------|------|------|
| 1차시 | 바이브코딩의 기초 원리 이해 | 제미나이 캔버스 |
| 2차시 | 캔바 AI로 경험해보는 바이브코딩 | Canva AI |
| 3차시 | 앱스스크립트 기초 | Google Apps Script |
| 4차시 | 앱스스크립트 심화 | Gems 챗봇 |
| 5차시 | 인공지능 API 소개 | 업스테이지 API |
| 6차시 | API로 AI 솔루션 주문하기 | API + 바이브코딩 |
| 7차시 | 안티그래비티 기초 | Antigravity |
| 8차시 | 깃허브 연동 + 웹 호스팅 | GitHub + Vercel |

## 🌐 배포

GitHub Pages로 바로 배포 가능합니다:

1. 이 저장소의 Settings → Pages → Source를 `main` 브랜치로 설정
2. `https://byeongjunpark.github.io/vibecoding/` 에서 접속 가능

## 🛠 기술 스택

- 순수 HTML / CSS / JavaScript (빌드 도구 없음)
- Google Fonts: Pretendard Variable, Fira Code
- localStorage: 체크리스트 진행 상태 저장

## 📁 파일 구조

```
vibecoding/
├── index.html          ← 메인 페이지
├── css/
│   └── style.css       ← 디자인 시스템
├── js/
│   ├── app.js          ← SPA 라우팅
│   ├── components.js   ← UI 컴포넌트
│   └── content.js      ← 8차시 콘텐츠 데이터
└── README.md
```
